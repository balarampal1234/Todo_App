# Todo App

A simple yet efficient web application that allows users to manage their daily tasks. The app provides an intuitive interface to add, view, and delete tasks, built with a clean and modular React architecture.

---

## Features
- **Add Tasks**: Quickly add tasks to your todo list.
- **View Tasks**: Display all tasks in a structured format.
- **Delete Tasks**: Remove tasks when they are no longer needed.
- **Fast Development**: Built using Vite for a seamless and efficient developer experience.
- **Modular Codebase**: Organized and scalable components for easy maintenance.

---

## Tech Stack
- **Frontend**: React.js
- **Build Tool**: Vite.js
- **Styling**: CSS
- **JavaScript**: ES6+ for interactive functionality
